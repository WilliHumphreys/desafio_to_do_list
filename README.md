# 📋 ToDo List – Desafio 01 | Ignite React Native

Este projeto foi desenvolvido como parte do **Desafio 01 da trilha React Native do Ignite**, da Rocketseat. Trata-se de um app de lista de tarefas (to-do list), com o objetivo de praticar conceitos fundamentais do React Native como estados, propriedades, componentização, listas e imutabilidade.

## ✨ Funcionalidades

- ✅ Adicionar uma nova tarefa  
- ✅ Marcar e desmarcar uma tarefa como concluída  
- ✅ Remover uma tarefa da lista  
- ✅ Exibir tarefas concluídas separadamente  
- ✅ Mostrar progresso da conclusão das tarefas  

## 🧠 Conceitos aplicados

- Estados com `useState`
- Manipulação de listas com `map`, `filter` e `includes`
- Componentes e propriedades
- Estilização com `StyleSheet`
- Componentização de `Input`, `Button` e `Task`
- Boas práticas com TypeScript
